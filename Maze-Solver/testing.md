# Testing and Calibration

The robot has been tested in different maze conditions and is currently working properly with the Left-Wall Following Algorithm.

## Sensor Calibration

The ultrasonic sensor thresholds were determined through trial-and-error testing.

The calibration was done based on factors such as:

- Sensor placement
- Distance from the maze walls
- Sensor readings
- Maze conditions

## Motor Calibration

The motor movement was adjusted during testing to achieve consistent movement and turning.

The main parameters tested included:

- Motor speed
- Forward movement
- Left turn
- Right turn
- U-turn
- Turning duration

## Navigation Testing

The robot was tested for:

- Detecting the left wall
- Detecting obstacles in front
- Moving through straight paths
- Taking left turns
- Taking right turns
- Handling blocked paths
- Navigating through the maze
- Reaching the destination

## Test Result

The robot is currently able to navigate the maze successfully using the Left-Wall Following Algorithm.

The sensor readings and motor movements were calibrated through testing to achieve reliable navigation.

## Future Testing

Further testing may be carried out with different maze layouts and conditions to improve the robot's reliability and navigation performance.
